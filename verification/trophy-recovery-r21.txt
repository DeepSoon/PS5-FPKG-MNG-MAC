PS5 FPKG Builder 1.4.3 - Trophy Recovery r21

Trophy Unlocker changes
- Detect Active Game still auto-loads the active game's Trophy2 catalog.
- Refresh Trophy List uses a state-only refresh when a catalog is already loaded.
- Added explicit TROPHY LOG header and Clear Log.
- Single Unlock: standard Trophy2 route first, then automatic UDS V12 fallback if still locked.
- Unlock All: standard pass -> immediate stop if complete -> UDS V12 recovery -> targeted remaining catalog ID ranges, Platinum last.
- Every recovery stage checks Trophy2 state and stops immediately once all catalog trophies are reported unlocked.
- Both PS5 trophy payloads are embedded; no external ELF is required.
