PS5 FPKG Builder 1.4.3 - Trophy Fast r19 verification

Changes
- Added Disconnect button and logical session reset.
- IP is locked while connected; Detect is disabled until Disconnect.
- Replaced ambiguous blank toolbar with explicit TROPHY LIST label + primary Get Trophy List button.
- Single Unlock fast verification: 3.0 s bounded window with ~280 ms polling.
- Unlock All: one fast all-pass, immediate stop when all trophies are unlocked.
- If trophies remain locked after the first bounded window, only one final all-pass retry is sent.
- Removed per-trophy retry fan-out from Unlock All.
- Loader send attempts reduced from 4 to 2; connect timeout reduced to 2.5 s.
- Embedded payload cached in memory.
- Static platform/NPWR/count command files cached per logical session; only the command config is rewritten each unlock.
- Existing r17 direct auto-build behavior remains unchanged.
