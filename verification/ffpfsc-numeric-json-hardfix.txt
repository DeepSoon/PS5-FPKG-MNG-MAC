PS5 FPKG Builder 1.4.2 - FFPFS/FFPFSC numeric JSON metadata hardfix

Problem:
- Some param.json variants store version/category/SDK fields as JSON numbers.
- Previous preview code always called JsonNode.GetValue<string>(), causing:
  An element of type 'Number' cannot be converted to a 'System.String'.

Fix:
- PackageParam.Text now accepts scalar JSON strings, numbers and booleans.
- Objects/arrays are ignored rather than coerced into metadata text.
- Decimal 64-bit packed SDK values are accepted by SdkVersion.Parse.
- Regression tests cover numeric contentVersion, applicationCategoryType and SDK fields.
