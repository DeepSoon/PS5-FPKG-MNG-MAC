PS5 FPKG Builder 1.4.3 - Trophy Unlocker r18 verification

Requested flow
- IP address field
- Detect Active Game
- Get Trophy List enabled only after a successful game/FTP connection
- Trophy list with ID, name, grade, status and group
- Unlock enabled only for a selected locked trophy
- Unlock All

Implementation
- Active PPSA detection through mounted PS5 FTP paths.
- Trophy2 NPWR resolution through appmeta/mounted npbind.dat.
- Trophy list read from TROPHY.UCP/trophy00.ucp.
- English metadata preferred with fallback locales.
- Read-only Locked/Unlocked status derived from validated TRPTITLE.DAT pages.
- Single unlock uses mode=id and the selected trophy ID.
- Unlock All sends mode=all, refreshes state, then retries remaining locked trophies individually; Platinum is retried last.
- NPWR and trophy-count override files are uploaded before unlock commands.
- PS5 r10 stable payload is embedded as FpkgExfat.TrophyUnlocker.Ps5R10.

Build/runtime limitation
- No Windows C# compiler is installed in this environment. START.cmd intentionally sees the internal revision mismatch and recompiles FpkgExfat.dll on Windows before launch.
- A real PS5 Trophy2 unlock cannot be exercised in this environment because no console is connected.
