GUIDA RAPIDA — BACKPORT UPDATE
PS5 FPKG Builder 1.4.5

SE HAI SOLO IL PKG (r30)
Apri “Extract file from PKG”. Puoi estrarre file scelti, reimportarli e creare
un nuovo PKG completo o un update con SDK senza fornire la cartella gioco.
Il salvataggio installabile ricava comunque il contenuto completo dal base.
Leggi GUIDA-PKG-EDITOR-ITA.txt per i passaggi e i limiti.

PRIMO AVVIO
1. Estrai tutto lo ZIP in una cartella normale di Windows.
2. Avvia START.cmd. Il programma ricompila automaticamente il modulo aggiornato.
3. Se Windows segnala un errore di compilazione, controlla build.log. Serve il
   compilatore .NET di Windows oppure il .NET 9 SDK, oltre al runtime richiesto
   dal programma.

CREARE UN PKG DI AGGIORNAMENTO
1. Apri Backport nella barra a sinistra.
2. Scegli il PKG base che è installato sulla console, per esempio PPSA03671.pkg.
   Il programma ne legge i metadati, non lo estrae e non lo modifica.
3. Scegli la cartella completa del gioco estratta dalla stessa versione del PKG
   base. Deve contenere sce_sys\param.json e sce_sys\keystone.
4. Scegli la cartella piccola con i file backport, per esempio eboot.bin,
   libcohtml.Prospero.prx, sce_module e fakelib. Il programma mostra i percorsi
   relativi al gioco.
5. Seleziona la casella Usa solo per i file da mettere nell'aggiornamento.
   I file riservati all'SDK sono disabilitati.
6. Per modificare un file, selezionalo e premi Sostituisci, oppure fai clic con
   il tasto destro e scegli Sostituisci file. Puoi aggiungere file o cartelle;
   per i nuovi file viene chiesto il percorso in cui inserirli nel gioco.
7. Inserisci la versione nuova nel formato 01.001.005. Non inserire il Content ID
   completo. La versione proposta dal programma è quella successiva al base.
8. Seleziona prospero-pub-cmd.exe del Sony SDK, la cartella di output e quella
   temporanea. Premi Crea PKG aggiornamento.

SALVARE O ESTRARRE SOLO I FILE SCELTI
- Salva file selezionati crea una cartella backport-selected con i soli file
  spuntati. Non crea un PKG.
- Seleziona una o più righe e premi Estrai selezionati, oppure usa il tasto
  destro > Estrai in... . La struttura delle cartelle viene mantenuta.
- Escludi rimuove quel file dall'overlay che stai preparando; non cancella un
  file già presente nel gioco installato.

COSA ASPETTARSI
- Il risultato è un PKG aggiornamento separato, chiamato per esempio
  PPSA03671-backport.pkg. Il PKG base rimane invariato.
- L'aggiornamento va installato solo sulla versione esatta del PKG base usato
  come riferimento, che deve essere quella presente sulla console.
- La preparazione copia solo i file scelti. Per creare il PKG, il tool del Sony
  SDK può comunque leggere a lungo la cartella completa del gioco e usare molto
  spazio temporaneo, potenzialmente vicino alla dimensione del PKG base.
- I log di img_create vengono conservati in una cartella chiamata
  <nome-base>-backport-logs accanto al PKG di output.
