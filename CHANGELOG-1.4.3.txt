1.4.3 r22 - Trophy Robust
- Moved Refresh Trophy List into the ACTIONS panel as a large visible button.
- Unlock All now targets the exact locked IDs from the active Trophy2 catalog instead of relying on a blind all/range pass.
- Non-Platinum trophies are processed first; Platinum trophies are handled last.
- Standard Trophy2 remains the first route; UDS V12 is used only for trophies that remain locked.
- Added UDS commit handling for titles that flush Trophy2 state only after the active game exits.
- Added payload-result diagnostics to TROPHY LOG when a route does not confirm the requested unlock.
- Folder and mounted-exFAT direct-build behavior remains unchanged.

1.4.3 r21 - Trophy recovery and log UX
- Added TROPHY LOG header and Clear Log action.
- Refresh Trophy List now refreshes state directly when the catalog is already loaded.
- Single Unlock uses the standard PS5 Trophy2 route, then automatically falls back to UDS V12 if the trophy remains locked.
- Unlock All stops immediately when complete, falls back from the standard route to UDS V12, and uses targeted remaining-ID recovery with Platinum last.
- Embedded both standard and UDS V12 PS5 trophy payloads.

1.4.3 r20 - Trophy Auto List
- Detect Active Game now automatically loads the Trophy2 list after finding the active PPSA.
- Renamed the manual list action to Refresh Trophy List; it remains available after connection.
- If automatic list loading fails, the active game connection is retained so Refresh can retry without reconnecting.
- Disconnect, fast Unlock and fast Unlock All behavior from r19 remain unchanged.
- Public version remains 1.4.3; internal revision is 1.4.3-trophy-auto-list-r20.

1.4.3 r19 - Trophy Fast / Disconnect
- Added an explicit Disconnect button to Trophy Unlocker.
- Added a visible TROPHY LIST label and primary Get Trophy List button so the toolbar is never ambiguous.
- Single Unlock now uses fast bounded verification instead of the previous long wait.
- Unlock All stops immediately when all trophies are reported unlocked.
- Removed per-trophy retry spam from Unlock All; at most one bounded all-pass retry is sent if needed.
- Cached the embedded trophy payload and static command context to reduce repeated work.
- Reduced loader connection retry count/timeout for a faster response.
- Public version remains 1.4.3; internal revision is 1.4.3-trophy-fast-r19.
